# Libot | 浙江大学图书馆座位空位提醒

这是一个 macOS 桌面小工具：每分钟刷新一次浙大图书馆座位系统，当你关注的馆舍出现空位时，会在钉钉群里推送提醒，并附上可直接打开的预约链接。

![进群二维码（钉钉群）](img/libot.JPG)

## 你可以做什么

1. 去本仓库的 GitHub Release 下载 `Libot.app`（macOS）
2. 在你的 Mac 上运行它

然后就会开始自动刷新，并在有空位时推送到群里。

## 重要说明：

群里的机器人消息是由这个软件“在运行时”发出来的

所以：

- 如果程序没有在某台电脑（一般是我本人的电脑）上运行（或那台电脑睡眠/断网），群里就收不到消息。
- 由于我（没有准备一台服务器）不可能一直保持它在我的电脑上 24 小时运行，所以如果你想稳定接收提醒，请下载 Release 的 `Libot.app`，在你自己的 Mac 上长期运行（本软件把 webhook 封装在 `.app` 内部）。

## 使用建议（macOS）

- 可以锁屏离开：程序默认会开启防睡眠，锁屏后仍可继续每分钟刷新/推送
- 注意：合盖通常会进入睡眠（系统限制），这时程序会暂停
